## 🚀 Featured Projects

### 🌿 WeedSight — Vision-Guided Precision Agriculture

A research-oriented agricultural rover concept exploring vision-guided weed identification and targeted, chemical-free weed treatment.

- **Focus:** Computer vision, robotics, embedded systems, precision agriculture.
- **Goal:** Explore how targeted weed treatment could reduce unnecessary chemical use.
- **Status:** Research and prototype development; experimental performance should be established through testing.

### 🤟 Syntalk — Sign Language Recognition

A wearable sign-language recognition concept combining glove-based sensor inputs with gesture classification to support communication accessibility.

- **Focus:** Sensor integration, gesture recognition, machine learning, and application development.
- **Goal:** Translate recognized gestures into understandable output.
- **Status:** Prototype development; recognition accuracy and real-world performance require validation.

### 🚨 Smart Accident Detection & Alert System

An ESP32-based engineering project combining motion sensing, GPS, and a web interface to explore accident detection and location monitoring.

- **Focus:** ESP32, MPU6050, GPS, Firebase, JavaScript, and mapping.
- **Goal:** Detect potential impact events and display location information.
- **Status:** Prototype development; detection reliability and location accuracy require testing.
